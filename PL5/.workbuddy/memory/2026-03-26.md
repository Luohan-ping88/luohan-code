## V5.3 升级（PL5 Python/C++ 整合性能优化）

完成对 PL5 项目 Python/C++ 整合层、工作流程运行机制的全面检查与优化，版本升级至 V5.3：

**C++ 核心算法复杂度优化：**
1. `rollingMean`：O(n×w) → O(n) 滑动求和，预期加速 10~30×
2. `rollingStd`：O(n×w) 双遍历 → O(n) Σx²在线算法
3. `rollingFrequency`：O(n×w×10) → O(n×10) 滑动计数数组
4. `fftTransform`：O(n²) 暴力 DFT → O(n log n) Cooley-Tukey 递归 FFT，加速 5~50×
5. `setup.py`：添加 `/openmp` + `/GL/LTCG`（Win）/ `-march=native -ffast-math -fopenmp`（Linux）

**Python 回退实现修复（pl5_core.py）：**
6. `HMMModel.fit/predict`：空操作 → 真实 GaussianMixture 拟合
7. `CopulaModel.fit`：空操作 → scipy.stats.kendalltau 真实计算
8. 所有 rolling_* 同步升级为 O(n) 算法，FFT 改为 numpy.fft

**特征工程消除 Python 循环（feature_engineering.py）：**
9. `extract_entropy_features`：for 循环 → rolling.apply(raw=True) + numpy bincount
10. `extract_chaos_features`：for 循环 → rolling.apply(raw=True)
11. `extract_fourier_features`：for 循环 → rolling.apply + C++ FFT
12. `extract_cross_correlation_features`：修复 spearmanr 索引错位 Bug → rank().rolling().corr()

**数据采集向量化（data_collector.py）：**
13. `calculate_rolling_features`：250 次 apply lambda → One-Hot + rolling().sum() 纯向量化
14. `calculate_basic_features`：apply(axis=1) → 列级向量化

16. 磁盘路径：psutil.disk_usage('/') → disk_usage(project_dir.anchor)（Windows 兼容）
