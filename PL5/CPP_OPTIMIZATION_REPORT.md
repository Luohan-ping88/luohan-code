```

GCC版本: 13.3.0
Python版本: 3.14.4
pybind11版本: 3.0.4
```

### 1.2 编译参数

使用最优化的编译标志：

```bash
g++ -O3 -march=native -funroll-loops -ffast-math -fopenmp -std=c++17 -fPIC
```

**优化说明**:
- `-O3`: 最高级别优化
- `-march=native`: 针对当前CPU架构优化（AVX/AVX2/SSE4）
- `-funroll-loops`: 循环展开
- `-ffast-math`: 快速浮点运算
- `-fopenmp`: OpenMP并行支持
