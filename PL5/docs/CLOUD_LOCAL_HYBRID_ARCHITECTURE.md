# PL5 云端+本地混合运行方案

## 概述

PL5 系统采用 **SOLO Code 云端自动化 + 本地调度器** 的混合架构，实现完整的24小时不间断运行。

```
┌─────────────────────────────────────────────────────────────────┐
│                        SOLO Code 云端                            │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │  每日 16:00 自动任务                                      │    │
│  │  • 系统全面检测与优化                                     │    │
│  │  • 代码质量检查                                           │    │
│  │  • BUG 自动修复                                          │    │
│  │  • 性能报告生成                                           │    │
│  └─────────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────────┐
│                        本地 Windows 电脑                          │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │  调度器 (auto_scheduler_v8.py) 24小时运行                │    │
│  │                                                          │    │
│  │  22:15 - 数据获取                                        │    │
│  │  22:15 - 模型评估                                        │    │
│  │  22:45 - 策略优化                                        │    │
│  │  00:30 - 模型训练                                        │    │
│  │  08:00 - 增量训练                                        │    │
│  │  10:00-20:00 - 预测验证                                  │    │
│  │  20:15 - 报告发送                                        │    │
│  └─────────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────────┘
```

## 架构说明

### SOLO Code 云端自动化任务

| 配置项 | 值 |
|--------|-----|
| 任务名称 | PL5每日系统检测与优化 |
| 执行时间 | 每天 16:00 (北京时间) |
| 任务ID | 5JS_DGN6B2YJYI |
| 状态 | 活跃 |

**职责：**
- 系统健康检查
- 代码质量检测
- BUG 自动修复
- 性能优化建议
- 日志分析

### 本地调度器

**职责：**
- 每日数据更新 (22:15)
- 模型评估 (22:15)
- 策略优化 (22:45)
- 模型训练 (00:30-17:00)
- 预测验证 (10:00-20:00)
- 报告发送 (20:15)

## 本地调度器配置

### 调度器配置文件

路径：`config/scheduler_config_v8.json`

```json
{
  "data_fetch_time": "22:15",
  "evaluation_time": "22:15",
  "optimization_start": "22:45",
  "training_start": "00:30",
  "training_deadline": "17:00",
  "email_send_time": "20:15",
  "enabled": true,
  "monitoring_enabled": true
}
```

### 启动方式

#### 方式1：命令行启动（推荐）

```batch
cd C:\PL5
python src/app/auto_scheduler_v8.py
```

#### 方式2：后台运行

```batch
cd C:\PL5
start /b python src/app/auto_scheduler_v8.py > logs/scheduler.log 2>&1
```

#### 方式3：使用启动脚本

双击运行：
- `start.bat` - 标准启动
- `start_daemon.bat` - 后台守护模式
- `start_pl5_foreground.bat` - 前台运行

#### 方式4：Windows 任务计划程序

1. 打开 "任务计划程序"
2. 创建基本任务
3. 设置触发器：每天 22:00
4. 设置操作：启动程序 `python.exe`，参数 `src/app/auto_scheduler_v8.py`
5. 工作目录：`C:\PL5`

#### 方式5：定时唤醒 + 自动执行

使用 `scripts/setup_wake_timers.bat` 设置 Windows 定时唤醒

## SOLO Code 自动化任务内容

当前配置每天 16:00 执行以下任务：

### 1. 训练推理性能检测
- 运行 PL5Predictor 预测功能测试
- 运行 ModelEvaluator 模型评估
- 检查训练逻辑和数据处理流程

### 2. 代码质量优化
- pytest 测试套件
- 代码导入依赖检查
- 错误处理验证

### 3. 智能功能检测
- PL5 工具执行逻辑
- Agent 编排器
- 智能调度集成

### 4. BUG 修复
- 日志文件检查
- verify_all_fixes.py 验证
- system_checker.py 系统检查

## 故障排除

### 调度器不运行

1. 检查 Python 环境：`python --version`
2. 检查依赖安装：`pip install -r requirements.txt`
3. 查看日志：`logs/scheduler.log`

### 数据不更新

1. 检查网络连接
2. 检查数据源 URL
3. 手动运行数据更新测试

### 邮件发送失败

1. 检查邮件配置：`config/email_config.json`
2. 验证 SMTP 设置
3. 检查网络防火墙

## 维护建议

1. **定期检查**：每周检查 SOLO Code 任务执行记录
2. **日志归档**：每月清理 `logs/` 目录
3. **数据备份**：定期备份 `models/` 和 `data/` 目录
4. **系统更新**：关注 SOLO Code 自动化任务的优化建议
