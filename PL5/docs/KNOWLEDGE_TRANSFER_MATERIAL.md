## 🎯 系统概述

PL5 排列五高阶数理分析预测系统是一个基于人工智能和机器学习的预测系统，用于分析和预测中国体育彩票排列五游戏的开奖号码。系统采用先进的智能体架构和向量数据库技术，结合多种机器学习算法，提供高精度的预测结果。

### 核心价值
- **智能预测**: 结合多种机器学习算法和智能体决策，提高预测准确性
- **自动化运行**: 7×24小时自动运行，无需人工干预
- **实时监控**: 免疫系统实时监控系统状态，自动处理异常
- **智能报告**: 自动生成详细的分析报告并发送邮件
- **持续优化**: 基于历史数据持续学习和优化

## 🚀 核心功能

### 1. 数据采集与处理
- **数据源**: 乐彩网 (lecai.com)
- **采集频率**: 每日自动采集
- **数据处理**: 清洗、去重、标准化
- **存储**: 本地文件系统 + 向量数据库

### 2. 特征工程
- **特征维度**: 700+维
- **特征类型**: 多尺度熵、GARCH波动率、格兰杰因果、Lyapunov指数、多窗口统计
- **特征计算**: C++加速模块

### 3. 模型预测
- **集成模型**: RF+GBM+ET+AdaBoost 4基模型 + LogisticRegression Stacking元学习器
- **权重融合**: 贝叶斯权重融合 + 智能体决策
- **调整模型**: HMM状态调整 + Copula联合调整 + BSTS趋势 + EVM极值
- **预测结果**: Top-8 推荐号码

### 4. 智能体决策
- **多Agent协同**: 5个智能体协同决策
- **MCP协议**: 标准化工具调用
- **RAG增强**: 检索增强生成，结合历史数据

### 5. 自动化调度
- **定时任务**: 5个核心任务
  - 00:00 获取开奖数据
  - 00:30 评估预测准确性
  - 01:00 策略优化学习
  - 02:00 智能体训练
  - 17:30 发送分析报告
- **任务调度**: Windows任务计划

### 6. 报告生成与发送
- **报告内容**: 预测结果、性能指标、状态信息
- **报告格式**: HTML格式，美观易读
- **发送方式**: 邮件自动发送

### 7. 系统监控
- **免疫系统**: 实时监控系统状态，自动处理异常
- **性能监控**: 系统资源使用情况监控
- **日志记录**: 详细的系统日志

## 🎯 快速上手

### 环境准备

1. **系统要求**:
   - Windows 10/11 (64位)
   - Python 3.8+ (推荐 3.12)
   - 内存: 16GB+ (推荐 32GB)
   - 磁盘: 20GB+ 可用空间

2. **安装依赖**:
   ```bash
   pip install -r config/requirements.txt
   ```

3. **配置邮件**:
   ```bash
   copy email_config.example.json email_config.json
   # 编辑 email_config.json 填写邮箱信息
   ```

### 系统初始化

1. **数据初始化**:
   ```bash
   python pl5_intelligent_system.py
   ```

2. **模型训练**:
   ```bash
   python pl5_intelligent_system.py
   ```

### 运行系统

1. **前台运行** (调试):
   ```bash
   python pl5_intelligent_system.py
   ```

2. **后台运行** (生产):
   ```bash
   python run_automation.py
   ```

3. **Windows任务计划** (推荐):
   ```bash
   PowerShell -ExecutionPolicy Bypass -File scripts\create_scheduled_tasks.ps1
   ```

## 🔧 常见问题与解决方案

### 1. 系统无法启动
- **症状**: 系统启动失败，出现错误信息
- **解决方案**: 检查Python环境和依赖，运行 `python -m monitor.system_checker`

### 2. 数据获取失败
- **症状**: 无法从乐彩网获取数据
- **解决方案**: 检查网络连接，确认 lecai.com 可访问

### 3. 智能体初始化失败
- **症状**: 智能体无法初始化，系统启动失败
- **解决方案**: 确保FAISS正确安装，检查智能体配置文件

### 4. 向量数据库构建失败
- **症状**: 向量索引构建失败，系统无法正常运行
- **解决方案**: 确保内存足够（至少16GB），优化向量索引参数

### 5. 邮件发送失败
- **症状**: 报告邮件无法发送
- **解决方案**: 检查邮箱配置，确认SMTP服务已开启

### 6. 定时任务不执行
- **症状**: 系统定时任务未按计划执行
- **解决方案**: 配置电源唤醒设置，重新创建定时任务
