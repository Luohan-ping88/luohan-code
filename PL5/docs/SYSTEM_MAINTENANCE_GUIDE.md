## 🚨 故障排查

### 常见故障及解决方案

#### 1. 系统无法启动

**症状**: 系统启动失败，出现错误信息

**排查步骤**:
1. 检查Python环境: `python --version`
2. 检查依赖: `python -c "import pandas, numpy, scipy, sklearn, schedule, faiss"`
3. 运行系统检查: `python -m monitor.system_checker`
4. 查看日志: `logs/pl5_system.log`

**解决方案**:
- 安装缺失的依赖: `pip install -r config/requirements.txt`
- 修复配置文件: 检查 `config/config.json`
- 重启系统: `python pl5_intelligent_system.py`

#### 2. 数据获取失败

**症状**: 无法从乐彩网获取数据

**排查步骤**:
1. 检查网络连接
2. 确认 lecai.com 可访问
3. 查看日志: `logs/pl5_system.log`
4. 检查数据采集模块: `python -m core.data.collector`

**解决方案**:
- 检查网络连接
- 等待乐彩网站恢复
- 使用备用数据源

#### 3. 智能体初始化失败

**症状**: 智能体无法初始化，系统启动失败

**排查步骤**:
1. 检查Python环境和依赖
2. 查看日志: `logs/agent.log`
3. 检查向量数据库状态
4. 运行系统检查工具

**解决方案**:
- 确保FAISS正确安装: `pip install faiss-cpu`
- 检查智能体配置文件
- 重新初始化智能体

#### 4. 向量数据库构建失败

**症状**: 向量索引构建失败，系统无法正常运行

**排查步骤**:
1. 检查内存是否足够（至少16GB）
2. 查看日志: `logs/vector_db.log`
3. 检查数据格式是否正确

**解决方案**:
- 增加系统内存
- 优化向量索引参数
- 重新运行数据初始化

#### 5. 邮件发送失败

**症状**: 报告邮件无法发送

**排查步骤**:
1. 检查邮箱授权码是否正确
2. 确认SMTP服务已开启
3. 检查网络连接
4. 查看日志: `logs/email.log`

**解决方案**:
- 检查邮箱配置: `email_config.json`
- 重新生成授权码
- 检查网络连接

#### 6. 定时任务不执行

**症状**: 系统定时任务未按计划执行

**排查步骤**:
1. 检查系统是否处于睡眠状态
2. 运行 `scripts\setup_auto_wake.bat` 配置唤醒
3. 检查Windows任务计划程序
4. 查看日志: `logs/scheduler.log`

**解决方案**:
- 配置电源唤醒设置
- 重新创建定时任务
- 检查调度器配置
