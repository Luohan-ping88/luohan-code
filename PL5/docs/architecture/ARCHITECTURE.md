## 智能体架构

### 智能体职责

| 智能体 | 职责 | 核心功能 |
|--------|------|----------|
| **Data Agent** | 数据采集与处理 | 从乐彩网获取数据，清洗、预处理 |
| **Research Agent** | 研究分析 | 特征分析、模式识别、趋势研究 |
| **Training Agent** | 模型训练 | 多模型训练、超参数优化、模型选择 |
| **Evaluation Agent** | 模型评估 | 多维度评估、性能分析、结果验证 |
| **Optimization Agent** | 策略优化 | 权重调整、策略改进、持续优化 |

### 多Agent协同决策流程

```
Data Agent → 数据采集与处理 → Research Agent → 研究分析 → Training Agent → 模型训练
                                                                 ↓
Evaluation Agent ← 模型评估 ← Optimization Agent ← 策略优化
     ↑                                                     ↑
     └─────────────────────────────────────────────────────┘
```

## 数据层架构

### 向量数据库
- **存储**: FAISS 向量索引
- **功能**: 高效相似性搜索、模式识别、历史数据检索
- **应用**: 特征向量存储、模型预测结果存储、历史模式匹配

### RAG检索系统
- **功能**: 检索增强生成，结合历史数据和模型预测
- **应用**: 智能推荐、模式分析、决策支持

## 模型链路

```
数据采集 → 特征工程(700+维) → 智能体分析 → Stacking集成(RF+GBM+ET+Ada)
                                    ↓
                              LogisticRegression元学习器
                                    ↓
                              贝叶斯权重融合 + 智能体决策
                                    ↓
                              HMM状态调整 → Copula联合调整 → BSTS趋势 → EVM极值
                                    ↓
                              向量数据库检索 → RAG增强 → 最终推荐
                                    ↓
                              归一化 → Top-8 推荐号码
```

## V8.0 新增特性

1. **智能体架构** — 多智能体协同工作，提高系统智能化水平
2. **向量数据库** — FAISS 向量索引，支持高效相似性搜索
3. **RAG检索系统** — 检索增强生成，结合历史数据和模型预测
4. **MCP协议** — 标准化工具调用，提高系统可扩展性
5. **免疫系统** — 实时监控系统性能，自动处理异常
6. **多Agent协同决策** — 智能体之间相互协作，共同决策

## 自学习闭环

```
预测 → 开奖 → 命中评估 → 记录历史 → 智能体分析 → 性能评估
                                    ↓
                    性能下降/连续下滑 → 触发重训练 → 智能体优化 → 下次预测
```
