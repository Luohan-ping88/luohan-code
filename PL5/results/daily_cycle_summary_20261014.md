## 四、出现的问题

本次运行未出现致命错误（0 ERROR / 0 Traceback），但发现并修复了 2 项源代码问题：

1. **【已修复】反馈闭环 KeyError** — `src/core/feedback_learning.py` 性能趋势分析直接索引历史记录 `a['overall_analysis']['top8_accuracy']`，而反馈历史文件 `models/feedback_history.json` 中存在旧格式记录（无 `overall_analysis` 键），导致 `learn_from_feedback()` 抛出 `KeyError: 'overall_analysis'`（非致命，已自动跳过）。**修复**: 过滤缺失键的旧记录后再取最近 3 条有效分析，已复现验证通过。
2. **【已修复】内存阈值噪声误报** — `src/core/utils/resource_manager.py` 动态阈值 `avg_memory + 2*std` 在低内存基线沙箱环境下收敛至 36.7%，ML 训练高峰期内存 38.1% 即触发 WARNING 噪声。**修复**: 增加 60% 安全下限（与磁盘阈值保底逻辑一致），语法验证通过。

**备注**: torch=2.14.1+cpu（已安装，Mamba/iTransformer 可训练）；"重复号码惩罚"保护机制正常触发（上期号码 70367 与模型原始预测高度重合时强制概率惩罚）；send_report 在 CI 环境自动跳过 SMTP 并回退本地保存（正常行为）。
