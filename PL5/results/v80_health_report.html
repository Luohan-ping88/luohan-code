🏗 系统架构全景

系统由两条并行的执行路径组成：轻量核心路径（main.py）和智能体路径（pl5_intelligent_system.py），共享底层数据/特征/模型层。

入

入口层 / Entry Points

launch.py → 启动分发器（--mode system/train/predict/service）
main.py → 轻量路径（--action train/predict/status）
pl5_intelligent_system.py → 智能体路径（完整7阶段流水线）
scripts/infinite_training.py → 无限迭代训练管理器

↕
A

编排层 / Orchestrator Layer

轻量编排器（src/core/orchestrator.py::PL5Orchestrator）：直接调用 DataCollector→FeatureEngineer→PL5Predictor，5阶段流水线
智能体编排器（src/agents/orchestrator.py::AgentOrchestrator）：管理5个 Agent，7阶段流水线，含免疫系统监控

↕
B

智能体层 / Agent Layer（仅智能体路径使用）

DataProcessingAgent — 数据采集/清洗/验证/特征提取（max_workers=8）
TrainingOptimizationAgent — 并行训练HMM/Copula/BSTS/EVM/Stacking，智能早停
ResearchAgent — 历史模式分析、异常检测、研究报告
EvaluationFeedbackAgent — 模型评估、性能监控、反馈生成
OptimizationAgent — 特征选择、超参数调优、预测策略优化
ImmuneSystem — 实时监控系统健康，异常自愈

↕
C

src/core/models/predictor.py::PL5Predictor — Stacking集成+HMM+Copula+BSTS+EVM，贝叶斯权重融合

🔄 数据流与执行流程

训练流程（7阶段）

Stage 1 · 数据采集

lecai API → 解析 → 校验 → 备份 → 版本管理

Stage 2 · 特征工程

750维特征：统计/窗口/Fibonacci/Markov/Fourier/遗漏/动量

Stage 3 · 研究分析

历史模式分析、异常检测、生成 research_report_*.md

Stage 4 · 模型训练

RF+GBM+ET+AdaBoost Stacking × 5位置 + HMM/Copula/BSTS/EVM

Stage 5 · 模型评估

Top-3命中率评估，性能监控

Stage 6 · 反馈优化

生成优化建议，特征/权重调整

Stage 7 · 报告生成

HTML训练报告 + 邮件发送

预测流程（5步）

Step 1 · 加载最新数据

调用 PL5DataCollectorV8.update_data()

Step 2 · 特征提取

FeatureEngineer.extract_all_features() → 取最后一行

Step 3 · 模型推理

PL5Predictor.predict(x, recent_data, top_k=8)

Step 4 · 贝叶斯融合

Stacking(55%) + BSTS(12%) + EVM(15%) + HMM(10%) + Copula(8%)

Step 5 · 输出报告

results/latest_prediction.json + 邮件推送

🤖 预测器架构（修复后）

# PL5Predictor.predict() 融合逻辑
for pos in ['wan', 'qian', 'bai', 'shi', 'ge']:

    # Stacking: RF + GBM + ET + AdaBoost → OOF meta-features → LR 元学习器
    p_stacking = stacking[pos].predict_proba_position(pos, x)   # shape (10,)

    # HMM: lag-1 条件频率转移矩阵（Laplace平滑）
    p_hmm = hmm_models[pos].predict(recent_seq)

    # BSTS: 指数加权历史频率（α=0.05）
    p_bsts = bsts_models[pos].predict(recent_seq)

    # EVM: 遗漏越大权重越高（last_seen 统计）
    p_evm = evm_models[pos].predict(recent_seq)

    # 贝叶斯加权融合
    p_fused = (0.55 * p_stacking
             + 0.10 * p_hmm
             + 0.12 * p_bsts
             + 0.15 * p_evm)
    top_k = argsort(p_fused)[::-1][:k]

🚀 后续优化建议

🔀

合并双编排器

将 src/core/orchestrator.py（轻量版）和 src/agents/orchestrator.py（智能体版）合并，通过参数控制是否启用 Agent 层，减少代码重复和维护成本。

📐

真实评估指标

src/core/orchestrator.py 的评估阶段补充真实的 Precision/Recall/F1 计算（基于每个位置 Top-K 命中率），而非直接赋值 accuracy。

⚡

Copula 向量化

CopulaModel.fit() 中 Kendall τ 的 O(N²) 嵌套循环改用 scipy.stats.kendalltau 批量计算，避免大样本训练瓶颈。

🧪

协同决策真实化

AgentOrchestrator._gather_agent_opinions() 中 research/optimization/evaluation Agent 的意见目前为硬编码模拟值，建议接入真实的分析结果。

📉

特征降维

750维特征中存在高度冗余（V8.0 记忆中提到 freq↔omission 相关性 r=0.605），建议在训练前对特征做 PCA 或 SelectFromModel 降维至 200维以内。

💾

模型增量更新

TrainingAgent._incremental_update() 已有框架，建议完善 partial_fit 逻辑，在新数据仅增加少量期号时避免全量重训练，节省约 90% 训练时间。
