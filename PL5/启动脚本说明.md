# PL5智能分析系统 - 启动脚本说明

## 📋 核心启动脚本（共3个）

| 脚本文件 | 用途 | 推荐场景 |
|---------|------|---------|
| `start.bat` | **主启动入口** (推荐) | 日常使用，前台运行 |
| `scripts/launcher.bat` | 完整启动器 | 前台运行，带详细检查和自动重启 |
| `start_daemon.bat` | 后台守护进程 | 无窗口后台运行，关闭后继续 |

## 🚀 启动方式

### 推荐：双击 `start.bat`
```
start.bat → call scripts/launcher.bat → python -m src.app.auto_scheduler_v8
```
- 前台运行，可看到输出
- 自动检查环境/依赖/文件
- 程序崩溃自动重启

### 后台：双击 `start_daemon.bat`
- 使用 pythonw.exe，无控制台窗口
- 关闭窗口后系统继续运行
